# 前端实现与检查细则

本文件保存 web/AGENTS.md 条件导航的 UI/检查配置细节。仅处理对应行为时读取对应章节。web/AGENTS.md 拥有前端
完成入口，根 AGENTS.md 拥有授权/启动，本文不重复流程。架构/视觉分别由现有前端架构与视觉设计规范拥有。

## 滚动与弹窗

运行时滚动职责只有页面/壳层边界容器和内部滚动面，都使用 graft-scrollbar。scrollbar-color/width/gutter 与
::-webkit-scrollbar 原生样式只能在 check-scrollbar-governance 已登记 allowlist 中，记录原因、范围和清理触发。
不能用历史债作为默认豁免；新增/修改滚动面同步测试及治理检查。检查整个 web/src，不退成 changed-file 扫描。

运行源码禁止 window/globalThis/bare alert、confirm、prompt。使用 t-dialog/DialogPlugin，默认居中由
TConfigProvider 统一声明。业务不得重复默认位置、加局部 top 或通过全局 CSS 改内部 DOM。full-screen、响应式
sheet/drawer 或尺寸证明需独立布局的大结果页可显式例外，不得形成第二模块默认值。检查覆盖全运行 src，排除
tests/mocks/generated 等非运行边界。

## 文案、主题、图表与调试

文案禁词只管可见 UI，不管 ai-plan、AGENTS、代码注释、测试名或开发文档。权限等稳定业务 code/key 的名称在模块
locales 本地化；未知项或迁移回退不是长期消息真相。列表空态维持 header/body/footer、分页和主题 token；active
filter/search 提供清除动作，只读页不伪造 create。不得把后台概览做营销 hero。

字体使用 TDesign/Graft token；必须固定的图标/代码/受限控件字号，在 font-size checker allowlist 写 selector、
值与原因。渐变/color-mix 验证明暗可读性与边框/状态语义。ECharts tooltip/legend/axis/splitLine/series/边框响应
主题；token 缺失回退只作最终兜底。主题/locale/尺寸变化须同步图表，至少有一次主题同步直接测试。装饰 SVG 可以
做图标/插画，不能伪装业务数据图表。

长期日志使用 shell-owned debug runtime，flag 为 tabs、tabs.layout、project.monaco 等模块命名空间；环境键
VITE_DEBUG_<MODULE>_<SUBMODULE> 与 owner 注释对齐。window.__GRAFT_DEBUG__ 只是开发者 API，真实状态归 debug
store。默认关闭，危险能力另受 DEV；控制台优先一行平铺可检索字段。临时探针置于真实事件边界，按最小作用域使用，
提交前移除/降级/收口。状态/路由/生命周期证据不足时使用 graft-frontend-behavior-investigation，不从猜测直接修复。

## Hygiene 与 i18n 检查配置

- ESLint unused-imports 保留 import/变量基线；deadcode:check 通过 knip 查文件/导出/依赖。
- deadcode:fix 仅修 knip 支持的未使用导出/依赖，禁止自动删文件；主 agent 复核 diff。
- dupcode:check 使用 jscpd，覆盖 src/app/layouts/modules/shared/api/router/store/utils/contracts/config。
  排除 tests、locales、assets、mock、generated 和构建缓存；目录排除在 knip.config.ts/.jscpd.json 写中文原因。
- 特定误报以精确排除收口，并在代码旁中文注明删除/重构时同步移除排除。合并只针对语义一致且更清晰的复用，
  不为指标制造万能组件或破坏 ownership。font-size:check 阻断非 allowlist 固定字号/font shorthand。
- 当前 hygiene 已进入 check、pre-push 和 CI 阻断。不要回退为工具先试点或将历史步骤当当前执行顺序。
- lint:i18n 是 strict key-first 唯一脚本，默认 STRICT_I18N_KEY_FIRST=true，check/CI 复用它。
- pre-commit 的 staged web/src、web/scripts/check-i18n-governance.ts、web/package.json 触发 lint:i18n；
  pre-push 同范围相对 base ref 触发。禁止新增同规则第二 CI 真相。
- lint:i18n 阻断 root/module exact key 重复、未用 key、聚合漂移、第二消息真相、fallback-only server key-first
  registry findings 和时间未绑定 locale。不同语义可有相同 value。可见时间禁止 undefined locale 或无参
  toLocaleString/toLocaleDateString/toLocaleTimeString；shared/observability formatter 接当前 vue-i18n locale。
- 治理测试覆盖禁词作用域、关键 title_key 解析、主题响应。Stylelint 约束 TDesign 样式覆盖；它不授权猜测 DOM。

修改 hook 时可用 GRAFT_LINT_BASE_REF=origin/main .husky/pre-push 验证；有 web 改动跑 hygiene，未命中可跳过，
然后继续后端 lint。实际命令与完成标准仍由 root/web AGENTS 和既有入口持有。
