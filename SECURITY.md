# Security Policy / 安全政策

## Reporting a vulnerability / 报告漏洞

Please report suspected security vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/GeWuYou/Graft/security/advisories/new).

请通过 [GitHub 私密漏洞报告](https://github.com/GeWuYou/Graft/security/advisories/new) 提交疑似安全漏洞。

Do not open a public Issue, publish exploit details, or include credentials, access tokens, personal data, or private infrastructure details in a report.

请勿创建公开 Issue、发布利用细节，或在报告中包含凭据、访问令牌、个人数据或私有基础设施信息。

## Report contents / 报告内容

Include the affected version or commit, affected component, impact, reproduction steps or a proof of concept, and any mitigations you know. Provide only the minimum sensitive information needed to reproduce the issue.

请提供受影响的版本或提交、受影响组件、影响范围、复现步骤或概念验证，以及已知缓解措施。仅提供复现问题所需的最少敏感信息。

## Scope and handling / 范围与处理

Use the private reporting channel for potential vulnerabilities in Graft source code, official release artifacts, configuration examples, and repository-managed automation. Reports are assessed privately; no response-time commitment is made by this policy.

Graft 源代码、官方发布产物、配置示例及仓库管理的自动化中发现的潜在漏洞，均应使用私密报告渠道。报告将以私密方式评估；本政策不承诺固定响应时限。
